# Sowa w Chmurach — dokumentacja techniczna

Nowa wersja gry **SowaJumper** (identyfikator w bazie `jumper`), etap **E6** planu prac (Analiza 3; projekt: Analiza 2, rozdz. 3.3). Gra powstaje jako **podgląd** w folderze `SowaWChmurach/`; stara gra działa dalej w `SowaJumper/`. Moduły ES na Sowim Silniku (`shared/engine/`), bez p5.js i bez warstw łatek.

Stan: **E6a** — checklista smaczków obecnej wersji (niżej) i rdzeń: kolumna 9 m z przejściem przez krawędź, automatyczne odbicia od platform, sterowanie przeciąganiem palca (ruch względny) i klawiaturą, sześć typów platform (gałązka, liść Monstery, chmurka, huśtawka, balkon, krucha gałązka), generator z gwarancją przejścia (autopilot w testach), liście (zielone, złote), combo, seria idealnych lądowań, ratunek kózki zamiast upadku, pięć stref wysokości (kolory nieba, chmury, gwiazdy), poziomy Chill / Arcade / Chaos, Tryb Przytulny, wyniki i zapis `submitRun("jumper", { score, height })`. Przeszkody Pracu / Amic, kózki-power-upy, Niebiański Ocean, oprawa stref, przechylanie telefonu, samouczek, instrukcja i muzyka — kolejne kroki E6 (8.5 w Analizie 3).

## Pliki

```text
SowaWChmurach/
  index.html      strona gry (ekran tytułowy w HTML, plansza na płótnie)
  style.css       wygląd ekranu tytułowego i paska wysokości
  package.json    { "type": "module" } — pliki .js to moduły ES
  config.js       wszystkie parametry (świat, kamera, sowa, poziomy, platformy, generator, liście, punktacja, ratunek, strefy, dźwięki)
  physics.js      ruch sowy: przeciąganie, klawiatura, grawitacja, przejście przez krawędź (czysta logika)
  platforms.js    sześć typów platform, huśtawka, lądowanie tylko z góry (czysta logika)
  generator.js    ścieżka platform z gwarancją przejścia, pułapki, liście (czysta logika z ziarnem)
  game.js         logika lotu (kamera, lądowania, liście, combo, ratunek, strefy, wynik) — bez DOM
  render.js       rysowanie na płótnie (kolumna, niebo strefy, platformy rysowane kodem, sowa, kózka)
  main.js         strona: silnik, interfejs, gesty, dźwięk, SowieProgress, SowieCloud
  docs/           ta dokumentacja i instrukcja dla gracza (README.md)
```

Jednostki: **metry i sekundy**. Świat: kolumna szeroka na 9 m — `x` od 0 do 9 (lewa krawędź 0), za krawędzią sowa wychodzi z drugiej strony; `y` — wysokość nad ziemią ogródka (ziemia na `y = 0`). Rysowanie: oś y ekranu w dół, więc punkt świata (x, y) rysujemy w (x, −y).

## `physics.js` — ruch sowy

- `wrapX(x)` — `((x mod 9) + 9) mod 9`; `wrapDelta(od, do)` — najkrótsza odległość w bok ze znakiem (`d − round(d / 9) · 9`).
- `createOwlBody(x = 4,5, y = 0)` → `{ x, y, vx, vy, pending (zaległe przesunięcie z przeciągania, m), dragged, facing (1 / −1) }`.
- `steerBy(sowa, metry)` — `pending += metry × 1,25`.
- `stepOwl(sowa, { left, right }, dt)`: gdy `|pending| > 1e−6` — przesunięcie `clamp(pending, ±14·dt)`, `pending −= przesunięcie`, `x += przesunięcie`, `vx = przesunięcie / dt`, `dragged = true`; inaczej gdy wciśnięty dokładnie jeden z klawiszy — `vx = clamp(vx ± 42·dt, ±9)`, `x += vx·dt`; bez klawisza — po przeciąganiu `vx = 0` (bez dryfu), po klawiszu `vx *= exp(−9·dt)` (poniżej 0,05 → 0), `x += vx·dt`. `facing = sign(vx)` przy `|vx| > 0,5`. Na końcu `x = wrapX(x)`, `vy = max(−22, vy − 30·dt)`, `y += vy·dt`.
- `flightTime(wzniesienie, v = 15,5)` — czas od wybicia do opadnięcia na wysokość `wzniesienie` (`(v + √(v² − 2·g·h)) / g`; `null`, gdy za wysoko); `apexOf(v)` = `v² / (2 · 30)`.

## `platforms.js` — platformy

- `createPlatform(typ, x, y, { phase = 0, path = true })` → `{ type, x, baseX, y (wierzch), width, phase, path (należy do ścieżki generatora), spent, fade, gone }`; nieznany typ — błąd „Nieznany typ platformy”.
- `platformX(p, t)` — huśtawka: `baseX + 1,4 · sin(2π t / 3,2 + phase)`; pozostałe `baseX`. `updatePlatforms(lista, t, dt)` — huśtawkom `x = platformX`, licznik `fade` maleje, przy 0 → `gone`.
- `landsOn(sowa, poprzednieY, p)` — tylko gdy platforma nie jest `spent`/`gone`, sowa opada (`vy ≤ 0`), stopy przeszły w tym kroku przez wierzch (`poprzednieY ≥ y − 1e−6` i `sowa.y ≤ y`) i `|wrapDelta(p.x, sowa.x)| ≤ width/2 + 0,28` (także przez krawędź kolumny). Od dołu sowa przelatuje przez platformę.
- `isPerfect(sowa, p)` — `|wrapDelta(p.x, sowa.x)| ≤ width · 0,3 / 2` (środkowe 30%).
- `land(p)` → `{ bounce, points }` z `PLATFORM_TYPES`; chmurka: `spent = true`, `fade = 0,35` (znika po odbiciu); krucha gałązka: `spent = true`, `fade = 0,5`, `bounce = 0` (łamie się, sowa spada dalej).

## `generator.js` — trasa

- `MAX_GAP = APEX × 0,82` (≈ 3,28 m) — największy odstęp w pionie między kolejnymi platformami ścieżki (zawsze osiągalny zwykłym wybiciem).
- `baseGap(h, poziom)` = `(1,5 + (2,9 − 1,5) · (1 − (1 − u)²)) · gap poziomu`, `u = min(1, h / 1200)`; `gapAt(h, poziom, random)` = `clamp(baseGap + (2·random − 1) · 0,35, 1, MAX_GAP)`.
- `xRange(typ)` — zakres środka: od `width/2 + 0,15 (+ 1,4 dla huśtawki)` do `9 −` tyle samo.
- `hardChance(typ, h, poziom)` — 0 poniżej `hardFrom[typ]`, potem `hardChance[typ] × hard poziomu × min(1, (h − od) / 200 + 0,25)`.
- `createGenerator({ random, difficulty })` → `{ fill(doWysokości, platformy, liście), skipTo(y, x), topY, pathCount }`. Stan: ostatnia platforma ścieżki (`lastY` = 0, `lastX` = 4,5), seria trudnych, następny balkon (150 m), licznik kolumn liści.
  - `fill`: dopóki `lastY < doWysokości`: `y` = 1,6 m (pierwsza) albo `lastY + gapAt(lastY)`; typ (`chooseType`): gdy `y ≥` następny balkon — `balkon` (następny o 150 m wyżej); inaczej jedno losowanie, kolejno liść / chmurka / huśtawka z sumowaną szansą `hardChance` (chmurka i huśtawka pomijane po 2 trudnych pod rząd), w przeciwnym razie `galazka`; `x` (`chooseX`): balkon — losowo w `xRange`; inne — `lastX ± losowo(0,6–3,6)` (gdy wypada poza zakres, w drugą stronę), przycięte do `xRange`; platforma z losową fazą; przed nią (od drugiej) dodatkowa platforma `extra`; kolumna liści `leafColumn`; seria trudnych +1 dla chmurki i huśtawki, inaczej 0.
  - `extra`: gdy odstęp ≥ 1,8 m i losowo < 0,3 — w połowie odstępu (± 0,3 m) platforma poza ścieżką (`path: false`): krucha gałązka (od 40 m, szansa `0,5 × hard poziomu`) albo gałązka; środek losowany w `xRange` (do 4 prób) co najmniej 2,4 m w bok (także przez krawędź) od obu sąsiednich platform ścieżki. Krucha gałązka nigdy nie leży na ścieżce.
  - `leafColumn`: nie nad balkonem i huśtawką, z szansą 0,45: 1–3 liście nad środkiem platformy na wysokości `y + 1,2 + i · 1` (w zasięgu wybicia); co 9. kolumna ma złoty liść na szczycie.
  - `skipTo(y, x)` (testy, `warp`): ścieżka dalej od podanej platformy; balkony przesuwają się nad `y`.

## `game.js` — logika lotu

- `comboLevel(seria)` = `min(5, 1 + floor(seria / 8))`; `zoneAt(h)` — indeks ostatniej strefy z `from ≤ h`; `perfectBonus(seria)` = `2 × min(seria, 10)`.
- `createRun({ difficulty = "arcade", seed = "sowa", cozy = false, random = null, safe = false })` — nieznany poziom → błąd; RNG trasy `createRng("<seed>|trasa")` (albo `random`); `state`: `difficulty`, `cozy` (tylko na Chill), `safe` (ratunek bez utraty życia — samouczek), `phase` (`run` | `rescue` | `over`), `time`, `owl` (start na ziemi, `vy = 15,5` — od razu się wybija), `keys`, `lives`/`maxLives` z poziomu, `cameraBottom` (start −1: metr ziemi ogródka), `height` (najwyższy punkt sowy), `zone`, `platforms`, `leaves`, `lastSafe`, `rescue`, `invulnerable`, `leafCount`, `leafPoints`, `bonusPoints`, `chain`, `combo`, `bestCombo`, `perfectStreak`, `bestStreak`, `perfects`, `bounces`, `rescues`, `score`, `endReason`.
- `update(dt)` — czas × 0,85 w Trybie Przytulnym; `invulnerable` maleje; `updatePlatforms`; w `rescue` tylko lot kózki; w `run`: `stepOwl` z klawiszami, lądowania, liście, wysokość i strefa (zdarzenie `zone { zone, id, name }` przy wejściu do nowej), kamera `cameraBottom = max(cameraBottom, y sowy − 8,8)`, `spawn` (generator do `cameraBottom + 32`), sprzątanie (platformy i liście poniżej `cameraBottom − 6`, zniknięte platformy, zebrane liście; ostatnia pewna platforma i cel ratunku zostają), wynik; gdy `y sowy < cameraBottom − 1,2` — ratunek.
- Lądowania (`vy ≤ 0`): spośród platform, na które sowa ląduje (`landsOn`), najwyższa → `bounceFrom`; inaczej, gdy stopy przeszły przez `y = 0` — ziemia ogródka (zawsze, także pod ekranem): `y = 0`, `vy = 15,5`, seria idealnych = 0, `bounce { platform: "ziemia" }`.
- `bounceFrom(p)`: `land(p)`; krucha gałązka — zdarzenie `crack { x, y }` bez odbicia; inaczej `y = p.y`, `vy = 15,5 × bounce`, `bounces + 1`, punkty platformy do `bonusPoints` (liść +10); idealne lądowanie: seria + 1, `perfects + 1`, `bestStreak`, premia `perfectBonus(seria)` do `bonusPoints`, seria combo + 1, zdarzenie `perfect { streak, bonus }`; nieidealne — seria = 0; pewna platforma → `lastSafe`; zdarzenie `bounce { platform, x, y, perfect, points }`; chmurka — `puff { x, y }`; pierwszy raz na balkonie — `balcony { y }`.
- Liście: niezebrany liść w odległości (wrapDelta w bok, w pionie od `y sowy + 0,55`) ≤ 0,75 m: złoty = 5 liści i 50 pkt, zielony = 1 i 10 pkt — × combo sprzed zebrania; `leafCount`, `leafPoints`; zdarzenie `leaf { kind, x, y, count, points, combo }`, potem seria combo + 1 (zdarzenie `combo { combo }` przy wzroście poziomu).
- Ratunek (`startRescue`): `rescues + 1`, seria idealnych = 0, combo o poziom niżej (`chain = max(0, (combo − 2) · 8)`), poza trybem bezpiecznym `lives − 1` (Tryb Przytulny: najwyżej do 1); przy 0 życiach — koniec (`over { reason: "upadek" }`). Cel (`rescueTarget`): ostatnia pewna platforma, gdy jest nieznikająca, pewna i między `cameraBottom + 1` a `cameraBottom + 10`; inaczej najniższa taka platforma; w ostateczności nowy balkon na środku 3 m nad dolną krawędzią. `phase = "rescue"`, `rescue = { time, fromX, fromY: cameraBottom − 1, target }`, przesunięcia i prędkości wyzerowane, zdarzenie `rescue { lives }`. Lot (1,4 s): `k = t / 1,4`, wygładzenie `k²(3 − 2k)`, x — po najkrótszej drodze do `target.x`, y — od `fromY` do `target.y` + łuk `sin(πk) · 1,5`; na końcu sowa na platformie, `vy = 15,5`, `lastSafe = cel`, `phase = "run"`, nietykalność 1,5 s, zdarzenie `rescued { x, y }`.
- Wynik: `floor(height × 1) + leafPoints + bonusPoints`.
- API: `state`, `update`, `takeEvents()`, `steer(metry)` (tylko w `run`), `setKeys(lewo, prawo)`, `setSafe(v)`, `end(powód = "gracz")` (zdarzenie `over { reason }`), `warp(m)` (testy: sowa `m` wyżej na nowym balkonie w kolumnie [2, 7], trasa dalej od niego, kamera i wysokość, zdarzenie `zone` przy zmianie strefy), `summary()` → `{ score, height (całe m), leaves, bestCombo, bestStreak, perfects, bounces, rescues, zone (id strefy), difficulty }`.

## `render.js` — rysowanie
